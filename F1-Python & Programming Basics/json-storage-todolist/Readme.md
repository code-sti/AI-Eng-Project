# To-Do List App (File-Based Storage)

A command-line to-do list that persists tasks to a local JSON file — your list survives closing and reopening the program.

## Run it

```bash
python todo.py
```

Requires Python 3.6+. No external dependencies (uses only `json` and `os` from the standard library).

## Example

```
--- To-Do List ---
1. View tasks
2. Add task
3. Mark task done
4. Delete task
5. Exit
Choose an option: 2
Enter task: Finish README for Project 2
Added: Finish README for Project 2
```
